As part of an experimentation team, I led an initiative to extend an existing trip-determination approach — originally built for the EMR PAYG trial — into new contexts it hadn't originally been designed for. This was highly iterative: several early assumptions about how well the original approach would generalise turned out to be wrong, which meant repeatedly revisiting the detection logic itself rather than just tuning existing parameters. To keep accuracy improving through these iterations, I introduced regression testing against real field data, so each change could be validated objectively rather than by intuition.
